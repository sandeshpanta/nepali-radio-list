    Get the data

    All stations are in one plain JSON file. No key, no sign-up.

    Download JSON

    Each station: id, name, province, frequency, address, stream_url, logo (path under public/), online, checked_at. Provinces: Koshi, Madhesh, Bagmati, Gandaki, Lumbini, Karnali, Sudurpashchim, World (outside Nepal).
